# Healthcare Claims Analytics

## 📌 Project Overview
This project focuses on analyzing healthcare claims data to identify cost drivers, patient utilization patterns, and readmission trends.

The goal is to transform raw healthcare data into actionable insights that support clinical and operational decision-making.

---

## 🎯 Objectives
- Analyze patient admission and readmission trends  
- Identify high-cost diagnoses and procedures  
- Evaluate utilization patterns across patient groups  
- Build interactive dashboards for stakeholders  

---

## 🛠 Tools & Technologies
- SQL (Data Analysis)
- Python (Data Cleaning & Transformation)
- Power BI (Dashboard & Visualization)
- Microsoft Fabric (ETL, Lakehouse)

---

## 📊 Project Workflow
1. Data Collection (Claims / Synthetic Dataset)
2. Data Cleaning & Validation
3. SQL-Based Analysis
4. Visualization & Dashboarding
5. Business Insights
